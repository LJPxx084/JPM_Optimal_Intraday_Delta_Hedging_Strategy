# JP Morgan Delta Hedging

Research project for simulating and comparing option delta-hedging strategies.

## Structure

- `data/`: raw, simulated, and processed datasets
- `notebooks/`: exploratory analysis and strategy comparisons
- `src/`: reusable simulation, pricing, execution-cost, strategy, metric, and visualization code
- `scripts/`: command-line experiment runners
- `tests/`: automated tests
- `outputs/`: generated figures, tables, and logs
